## Featured Project

### AI Barbershop Appointment Assistant

A personal project built with n8n to explore how an AI agent can handle barbershop appointments through natural language.

The workflow includes:

- Appointment scheduling, rescheduling, and cancellation
- Google Calendar integration
- Google Sheets integration
- Availability checks
- Debugging real issues during development and testing
